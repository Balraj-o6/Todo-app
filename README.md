📝 Django Todo App

A simple Todo List application built with Django. This app allows users to add, view, mark complete/incomplete, and delete tasks. It’s a beginner-friendly project to understand Django’s Model-Template-View (MTV) architecture.

🚀 Features

➕ Add new tasks

👀 View all tasks

✅ Mark tasks as completed/incomplete

❌ Delete tasks

🛠️ Tech Stack

Backend: Django (Python)

Database: SQLite (default, can be changed to MySQL/PostgreSQL)

Frontend: HTML (Django Templates)
